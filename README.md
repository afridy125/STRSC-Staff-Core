# STRSC Staff Core

An all-in-one staff and moderation plugin for Paper/Spigot servers. STRSC Staff Core is a patched build of [Staff++](https://github.com/garagepoort/staffplusplus), with its credits and license kept. It is built for the Starscourge server.

**Version:** 26.2.0 | **API:** 1.13+

## Features
- **Staff mode and vanish:** configurable modes and modules, staff fly, night vision, staff list
- **Moderation:** ban, tempban, kick, mute, tempmute, warnings with appeals, and GUIs to manage them
- **Reports and investigations:** player reports, investigation workflow, staff notes
- **Player tools:** freeze, examine, follow, teleport tools, CPS check, strip, protect player/area
- **Chat tools:** staff chat, chat channels, phrase detection, mention alerts, blacklist
- **Extras:** web UI domain, optional server sync across a network, AuthMe login support

## Installation
1. Download the jar from the Releases page.
2. Drop it into your server's `plugins/` folder.
3. Start the server, then edit `config.yml` and the files in `configuration/`.

## Soft dependencies
PlaceholderAPI, LuckPerms, Vault, GroupManager, AuthMe, DiscordSRV, PacketListenerAPI
